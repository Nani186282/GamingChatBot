
# PUBG Gaming Assistant Chatbot 🎮

A simple, interactive, web-based chatbot designed to answer frequently asked questions related to PUBG gaming.

## 📌 Project Overview

The **PUBG Gaming Assistant Chatbot** is a frontend-based web application developed using HTML, CSS, and JavaScript.

The chatbot allows users to enter questions related to PUBG and receive predefined responses based on keyword matching.

It provides a simple chat interface where users can interact with the chatbot and get quick information about supported PUBG-related topics.

## 🎯 Project Objectives

- Develop an interactive chatbot using frontend web technologies.
- Provide quick answers to common PUBG-related questions.
- Implement keyword matching using JavaScript.
- Create a simple and user-friendly chat interface.
- Understand JavaScript concepts such as functions, conditions, string methods, and DOM manipulation.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Structure of the chatbot interface |
| CSS3 | Styling and user interface design |
| JavaScript | Chatbot functionality and response processing |

## ⚙️ Key Features

- Interactive chatbot interface.
- User message input and response display.
- JavaScript-based keyword matching.
- Predefined responses for supported PUBG topics.
- Fallback response for unrecognized questions.
- Simple and user-friendly design.

## 🧠 How It Works

1. The user enters a question in the chatbot interface.
2. JavaScript captures the entered message.
3. The message is processed using the implemented text-handling logic.
4. The chatbot checks the message against predefined keywords.
5. If a matching keyword is found, the corresponding response is displayed.
6. If no matching keyword is found, the chatbot displays a fallback response.

## 💻 System Requirements

- Modern web browser (Google Chrome, Microsoft Edge, Firefox, etc.).
- Basic computer with a supported operating system.

## ⚠️ Current Limitations

- Uses predefined responses and keyword matching.
- Supports only the topics configured in the JavaScript code.
- Does not use machine learning or generative AI.
- Does not connect to a backend or database.
- Does not retrieve real-time PUBG game information.
